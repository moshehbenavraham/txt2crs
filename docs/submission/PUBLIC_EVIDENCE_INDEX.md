## Screenshot Redaction Review

Every captured frame must pass all of these checks before its row can be
marked `PASS`:

- synthetic nonpersonal topic and, where visible, synthetic test display only;
- no real email address, user identifier, avatar, browser profile, account
  menu, or notification content;
- no password, API key, device code, cookie, token, authentication state, or
  environment value;
- no prompt transcript, hidden reasoning, provider response, raw evidence
  excerpt, token usage, or checkpoint body;
- no filesystem path, private artifact URL, unrestricted download, developer
  console, network panel, trace, or implementation diagnostic;
- no unsupported legal, GDPR, retention, provider-deletion, or hosted-service
  claim; and
- no student answer visible inside the student assessment; solutions appear
  only in the separate instructor answer-key frame.

All six reviewed frames pass this checklist.

## Public Versus Private Evidence

The tracked images and bounded release tables are public evidence. Raw screen
recordings, browser profiles, live account state, private artifacts, and edit
intermediates remain outside Git. Exact hash and dimension rows identify the
reviewed public bytes without exposing their private source material.
