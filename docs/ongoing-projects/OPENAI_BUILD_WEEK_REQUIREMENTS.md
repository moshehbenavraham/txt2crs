# OpenAI Build Week Requirements

**Last verified:** July 17, 2026<br>
**Official event:** [OpenAI Build Week on Devpost](https://openai.devpost.com/)<br>
**txt2crs track:** Education

## Build Requirements

- Deliver a working project created using **Codex with GPT-5.6**.
- Enter one category. txt2crs belongs in **Education**, which covers projects that
  advance AI for students, teachers, or educational organizations.
- Clearly explain what the project does, how it works, how Codex accelerated
  development, which key decisions were made, and how Codex and GPT-5.6 were used.

## Required Deliverables

- A working project
- The selected category
- A project description
- A public YouTube demo video shorter than three minutes
  - The video must show the project working.
  - Its human or AI-assisted voiceover must explain the project and the use of both
    Codex and GPT-5.6. A music-only screencast does not qualify.
- A public or private code-repository URL
  - A public repository must include an appropriate license.
  - A private repository must be shared with `testing@devpost.com` and
    `build-week-event@openai.com`.
  - Its README must include setup instructions, any required sample data, and clear
    run instructions.
- The `/feedback` Codex Session ID from the session in which most core functionality
  was built
- Required form answers for submitter type and country of residence

A hosted project URL is optional, and neither a website nor a ZIP upload is required.
