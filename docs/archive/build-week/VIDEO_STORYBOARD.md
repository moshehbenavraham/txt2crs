"The backend commits that request before accepting the job. The reusable

to an older model."

### 00:48-01:02 - Durable Progress

"Progress comes from accepted checkpoints, not a fake timer. I can refresh

## Capture Procedure

1. Start the deterministic browser application with
   `TXT2CRS_BROWSER_SCENARIO=complete` and project `chromium`.
2. Use the synthetic `Teach Python variables.` request and the test-owned
   account only.
3. Capture at a stable 1440x900 product viewport with browser chrome, desktop
   notifications, and unrelated applications excluded.
4. Record the landing page, create form, one submit action, refresh-safe
   progress, completed results, course preview, sources, assessment, and
   answer key in storyboard order.
5. Capture the repository architecture and bounded release index without a
   terminal path, credential, private Git remote value, or developer console.
6. Record narration in a quiet track, normalize speech, and keep background
   audio absent or comfortably below the voice.
7. Edit on a 1920x1080 canvas at 30 fps with short cuts and no decorative
   transition that hides product behavior.
8. Export H.264 video plus AAC audio, inspect the complete render, and measure
   duration with `ffprobe`.

## Public Safety Capture Review

- Use synthetic content and the deterministic test account only.
- Exclude email addresses, avatars, passwords, API keys, device codes, cookies,
  tokens, browser profiles, desktop notifications, and account menus.
- Exclude prompts, hidden reasoning, raw provider responses, checkpoint JSON,
  token usage, trace details, console output, network panels, and local paths.
- Do not open an unrestricted private artifact URL or publish an artifact body
  outside the inert preview shown by the product.
- Do not claim hosting, public personal-data readiness, GDPR compliance,
  provider deletion, or a defined retention policy.
- Confirm the student assessment frame contains no answer and the instructor
  answer-key frame is visibly separate.
