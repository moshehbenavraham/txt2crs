## Product Story

txt2crs turns one bounded source into four coordinated learning
publications:

1. a deep-researched course;
2. a comprehensive review pack;
3. a student assessment; and
4. a separate instructor answer key.

Each publication is rendered in HTML, Markdown, PDF, and DOCX. The learner
receives a durable, refresh-safe job journey with source disclosure,
owner-private artifacts, integrity-checked downloads, and inert HTML preview.

The submission must clearly distinguish:

- Codex as the development collaborator;
- exact `gpt-5.6-sol` as the default course-generation runtime model;
- Tavily as bounded research through the engine-owned MCP boundary;
- deterministic synthetic proof from the historical paid live proof; and
- the reusable engine from the FastAPI/React application shell.

## Human-Only Publishing Boundary

The agent prepares local assets, checks, and instructions. Only the human
operator may:

- change GitHub visibility or invite repository reviewers;
- create or push a release tag;
- push the final branch;
- authenticate to YouTube or Devpost;
- upload or publish the demo video;
- enter account-only Devpost answers;
- create, edit, or submit the Devpost entry; or
- preserve platform receipts and final URLs.

The repository remains Private. Required reviewers receive explicit private
access; public visibility is not a fallback.
